## 2026-10-11 成本蠕变架构重构：基础蠕变 + 动态蠕变

- 改动：
  - **架构重构**（按用户技术说明）：删除余额调整表（`BASE_CREEP_TIERS`），蠕变分为两层——
    - **基础蠕变**：建筑注册表系数（`costScales`），固定数据，仅游戏更新时改动；同建筑每种材料可有不同系数；
    - **动态蠕变**：游戏过程中生效的系数（默认0），当前来源：CRISPR 材料基因（-0.01~-0.05 按最高级）、工业至上体制（工厂 -0.005）、中子结构建材（猫窝 -0.01）；多个动态系数**逐项累加**；
    - **实际蠕变 = 基础系数 + Σ动态系数**（下限1）；新增 `calculateDynamicCreep` 返回带标签的动态项列表（可扩展、可展示）。
  - **基础系数按当前数值固化**：注册表系数即当前各建筑的实际基础蠕变（剧场 1.17、粮仓 1.25、工厂 1.17 等，逐项核对无误）；此前余额调整表中 +0.02/+0.03 的附加蠕变随调整表一并移除，这些建筑现在的实际蠕变与其注册表系数一致。
- 兼容：无存档影响；数值行为与重构前一致（255项测试全过）。
- 验证：**255 项 TS 测试** + 全部保留回归 + Edge 浏览器验收 + 严格类型检查 + 生产构建。

## 2026-10-11 存储建筑容量语义重构与蠕变再平衡
