## 恢复旧版程序（推荐独立目录）
1. 先在游戏设置导出当前存档，并导出“升级前原档”。
2. 将压缩包解压至另一个空目录，不覆盖当前开发目录。
3. 在该目录执行 npm ci，再执行 npm run dev，或使用压缩包中原版dist构建。
4. 在旧版导入“升级前原档”（存档版本29）。不要向旧版导入新版版本30存档。
5. 旧版和新版若使用同一个网页来源会共享localStorage；建议使用不同端口，避免相互覆盖。

## 游戏内存档恢复
- 新版本首次成功读取旧档时，以独立localStorage键备份升级前原档，只写一次。备份失败时阻止自动覆盖原档。
- 每次第四阶段结局前另存独立结局恢复点；备份失败则不重置。
- 设置页面可分别导出或恢复两个备份。恢复替换整个当前进度，不合并威望奖励。
- 浏览器本地数据清除也会清除恢复点，请务必下载JSON副本。
- 在新版本恢复升级前进度会再次迁移为新版，并不是把程序代码降级。代码降级请使用上面的压缩包。
