# 喵星文明 / Eden_Kittens

从登陆的第一只猫猫，到登陆月球与探索 Asriel 的静态增量游戏。

采用 **Vue 3 + TypeScript + Vite**：生产、资源、建筑、科技、人口、太空、威望等规则位于纯 TypeScript 模拟层，Vue 负责展示，通过显式 store 与 runtime 连接。无需后端，存档保存在浏览器 localStorage。

## 运行与部署

建议使用支持当前 Vite 的 Node.js 版本（例如 Node.js 22.12+；最近验证环境为 Node.js 24）。

```sh
npm install
npm run dev       # 开发服务器，绑定 0.0.0.0（局域网可访问）
npm run typecheck # TypeScript + Vue 模板检查
npm test          # 模块测试 + 保留 VM 回归
npm run test:browser
npm run build     # 构建静态网站
npm run preview   # 本地预览构建产物
```

已安装依赖且希望严格按锁文件安装时，可以使用 `npm ci`。

[vite.config.ts](<vite.config.ts>) 使用 `base: './'`，产物可部署在域名根路径或子目录。生产构建目标为 ES2022；不建议通过双击 HTML 文件代替 HTTP 服务运行。

### 存档安全

- 正常运行时按真实经过时间触发约每 10 秒自动保存；设置页提供立即保存、JSON 导出与导入。
- 导入先进行版本迁移、类型与玩法约束校验，再替换状态。
- 无法读取或校验已有本地存档时，runtime 保护原始存档，不让临时新游戏自动覆盖它。
- 更换域名、协议、端口或浏览器前先导出存档；不同来源的 localStorage 不共享。
- 历史存档会补充缺失设置、统计及近期新增建筑字段；不应手动删除迁移和兼容校验。
- 软重置与核爆保留粒子、永久 CRISPR 升级、成就、累计统计及设置；清除本周目内容。硬重置恢复初始状态。

## 当前功能概览

### 地面经济与人口

- 资源生产、持续消耗、仓储、集装箱、建筑递增价格、科技前置与资源解锁。
- 猫猫岗位、幸福度、人口增长、税收、政府体制、军事训练与核爆威望。
- 工厂共享生产线；工匠自动锻造与左侧手动锻造，支持倍率操作。
- 资源耗尽后的连续饥饿计时、死亡处理与岗位裁剪。
- 建筑默认不再统一限制为 300 座；有明确上限的建筑仍遵守其上限。
- 每座猫咖提供 1 个名额，直接并入原有艺术家岗位；艺术家总容量来自剧场与猫咖。旧猫咖独立岗位分配载入时合并，不丢失人数。
- 秘银属于无储量上限的锻造物，**不支持集装箱分配**；旧秘银集装箱分配载入后归还为空闲，总箱数与秘银数量保留。

### 界面与信息

- 地面 / 太空视图，科研可研究列表 / 已研究树，统计信息 / 成就子页。
- 设置、资源管理、Tips、工厂弹窗、日志筛选与共享悬浮详情。
- 资源产量详情展示收入、消耗及倍率，并在右下角显示按当前净产量估算的满仓 / 耗尽时间；达到边界时显示“已达到储量上限”或“已降为0”。
- 建筑与科研队列分栏：研究在上，建筑在下；无 emoji，每行 4 个项目。
- 队列项目显示预计完成时间或“储量上限不足”“暂无完成时间”“等待前序项目”等状态。
- 建筑 / 研究队列悬浮详情复用对应按钮信息；ARPA 项目显示名称、描述及扣除已投入进度后的剩余资源需求。

### 设置与队列

| 设置 | 默认值 |
|---|---|
| 暂停游戏 | 关 |
| 总是启用新建筑 | 关 |
| 乱序建筑队列 | 开 |
| 队列快捷键 | 开 |
| 触摸屏优化 | 关 |
| 乱序研究队列 | 开 |

- 建筑容量初始为 **2**，研究容量初始为 **2**。
- **ARPA 属于建筑队列**，与普通建筑共同占用容量。
- 社区管理员（T3，1000 知识，前置猫猫社区）：建筑 +2、研究 +1。
- 科学行政优化（T6，15000 知识，前置科学方法与自动化）：建筑 +2、研究 +2。
- 智能管理系统（T9，50000 知识，前置人工智能与数据中心）：建筑 +6、研究 +3。
- 三项全部完成后容量为 **建筑 12 / 研究 8**。
- 按住 Q 点击建筑或科技可以强制入队，即使当前资源充足；Ctrl ×10、Shift ×25、Alt ×100 可组合。当前实现也保留 Shift 点击强制入队行为。
- 乱序开启时普通建筑和研究可以跳过当前无法支付的同类项目；关闭后按同类顺序等待。ARPA 仍由专门的分段投入结算器处理。
- 底层继续保留 `GameState.queue` 的混合结构，通过 `kind` 分类，兼容旧存档。
- 时间是**当前生产状态下的估算，不是固定施工时长**；前序消费、跨队列竞争、手动操作、后续产量变化可能改变结果。

## 太空与 Asriel

太空页按 **Eden_Kittens → 月球 → Asriel** 分栏，区域按解锁情况显示。Asriel 探索任务和建筑集中在月球下方的 Asriel 栏目。

- 月球基地、导航信标提供月球支持；铱矿、氦-3矿及月球观测站按优先级获得支持。
- 月球观测站在获得支持时提供知识容量与学校容量加成。
- 行星勘探开放 Asriel 探索任务；基础需求 **5000 氦-3**，完成后解锁太空港。
- 每座运行的太空港提供 **4 Asriel 支持**；居住站、矿井、生态穹顶各需要 1 支持。
- Asriel 居民手动分配，每座居住站提供 2 个岗位。
- 太空工厂与地面工厂共享生产线；星环只提高指定太空来源产出。
- 星环空间站与太空驿站为被动、始终运行建筑；导航信标有供能启停控制。

## 粒子与 CRISPR

### 产量软上限

实际粒子数不会被截断；仅**产量加成**转换为有效粒子数。默认参数为软上限 `S = 400`、前段强度 `a = 0.2`、后段尺度 `L = S / 2 = 200`。

```text
P <= S：E(P) = (S/a) × ln(1 + aP/S)
P >  S：E(P) = (S/a) × ln(1+a) + L/(1+a) × ln(1 + (P-S)/L)

普通资源倍率 = 1 + E(P) × 0.005
锻造物倍率   = 1 + E(P) × 0.00125
电力倍率     = 1
```

两段在软上限处数值及斜率连续，不按每 200 个做阶梯取整。400 以下轻微递减，以上递减加速；新增粒子始终增加收益。自动 / 手动锻造共享同一计算。

**空间推理储量加成不使用有效粒子数**：普通有限容量资源按实际持有粒子数，每粒子 +0.04% 储量，线性计算；锻造物与特殊资源不套用该储量加成。

### 永久升级

CRISPR-16 为特殊层级科技，要求完成基因测序；研究后开放 ARPA 的永久修饰页。七项升级为材料效率、创新材料、结构强化、物理定律、半条命3、基因优化、空间推理。升级消耗实际粒子，软重置与核爆后保留效果，但新周目研究入口仍需要本周目解锁。

核爆单次粒子奖励的原有软上限与上述**持有粒子产量软上限**是两个独立规则，不要混用。

**响应式约定**：模拟层是普通可变状态，不依赖 Vue 或 DOM。组件的 computed 读取状态时必须同时读取 `props.revision`；仅返回同一个 state 引用无法使缓存自动失效。操作通过 `store.mutate()` 修改状态；加载、导入与重置由 runtime 统一处理，并刷新版本号。

**规则单一来源**：UI 使用模拟 helper 获取价格、消耗、容量和支持，不重新写一份简化公式。新增建筑 / 科技时检查类型、目录、区域、解锁、初始状态、旧存档字段、悬浮详情和 legacy bridge。

## 已知边界与后续检查项

这些是当前源码检查得到的限制 / 不一致，记录在此方便继续开发，不把测试通过等同于所有需求已彻底解决：

- 暂停开关当前阻止 live tick，但没有持续重置时钟；恢复时可能补算暂停期间经过的时间，载入也仍执行离线模拟。若要求暂停时间彻底不结算，需要补充实现与专门测试。
- “总是启用新建筑”目前明确覆盖月球支持不足的默认停用路径；一般建筑电力 / 全部支持不足时的默认停用行为需要进一步统一。
- ARPA 与普通建筑共享容量及显示栏目，但 ARPA 仍有独立结算器；严格统一 FIFO / 乱序执行顺序需要后续审查。
- 队列估算不模拟未来科技、建筑收益或纪念碑随机材料变化；不应作为精确完成承诺。
- 科研卫星建筑悬浮说明为“科学家知识产量 +1%”，当前生产公式及科技描述仍为每座 +2%，需要确认最终平衡值再统一。
- Q 快捷键的失焦清理、Shift 与强制入队交互，以及科技树同层前置横向线路，仍值得增加专项验收。
- beta 展示版本、npm 包版本和存档 schema 各自独立；升级展示版本不要直接改 schema，只有确实需要迁移时才升级存档版本。

## 维护原则

优先修改 TypeScript/Vue 源码与真实回归测试；平衡数据以数据目录为准。不要删除存档兼容入口，也不要把生成 bridge 当作第二套手工规则实现。清理截图、调试或构建文件不应触及浏览器存档；发布前导出备份并完成上述四步验证。
